# Sudarsan Sharma Portfolio
Responsive portfolio with a dark starfield, glowing purple/cyan accents, experience timeline, project carousel, contact form, and opt-in ambient music.

## Files
- `index.html`: content and FormSubmit contact form
- `style.css`: styling and responsive layout
- `script.js`: starfield, animations, carousel, and generated ambient sound

## GitHub Pages deployment
1. Upload all three files to the root of your GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select your main branch and `/(root)`, then save.
4. Wait for GitHub Pages to publish the URL.

## Contact form
The form sends messages through FormSubmit to `sudarshansharma9863@gmail.com`. On the first submission, check that inbox for a FormSubmit activation email and confirm it. Static GitHub Pages needs a form service because it cannot process form submissions on its own.

## Music
Browsers generally block sound autoplay before a visitor interacts with a page. This portfolio generates gentle ambient tones in the browser; visitors can start or stop them with the Music button.

Review experience dates and project descriptions before publishing.
